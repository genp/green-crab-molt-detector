  How to run FastAPI locally

  1. . .venv/bin/activate
  2. Optional: set YOLO_MODEL_PATH=/path/to/yolo.pt for bboxes (otherwise bboxes returns empty).
  3. uvicorn app_fastapi:app --host 0.0.0.0 --port 5001
     Endpoints: /predict (single image), /predict_stream (frame uploads, same response structure, includes thumbnail and bboxes), /health.

  Notes on streaming/bboxes

  - thumbnail is a 320px JPEG with phase + days overlay; bboxes are drawn when a YOLO detector is configured. Without a detector, bbox list is empty
    but the endpoint still responds.
  - Concurrency capped via MAX_CONCURRENT_INFERENCES env (default 2). Frame queue/backpressure is per-request; front-end polling/WS still to be wired.
