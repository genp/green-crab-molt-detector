Using ChatGPT Web to Explain llm_checkwork.py

Source files live in ~/Practical ML Tools for Climate Change Course Materials/

Goal: use the web version of ChatGPT to generate the step-by-step logic, then verify every claim against the notebook and data files.

Prompt pattern

Ask for structure first, not code first

Read llm_checkwork.py and explain each block in order.
Use the source data in:
  - icecore/vostok.icecore.co2
  - icecore/vostok.1999.temp.dat
  - modern_climate/co2_mm_mlo.txt
  - modern_climate/Land_and_Ocean_complete.txt

Return:
  1. a concise step list
  2. file dependencies
  3. any assumptions that need verification

This keeps ChatGPT focused on explanation and provenance before it starts narrating results.

Notebook map

What the script actually does

  1. Load Vostok CO2 and temperature tables from the course materials.
  2. Merge them on age using nearest-time alignment.
  3. Sort in reverse chronology and plot temperature and CO2.
  4. Compute Pearson correlation and mutual information.
  5. Fit orbital-cycle priors with 2-cycle and 3-cycle models.
  6. Compare paleo and modern CO2 with a Welch t-test.
  7. Forecast temperature anomalies with linear, bootstrap, and Bayesian models.

Verification

Use ChatGPT as a checker, not as the source of truth

  • Confirm skiprows and column names match the files.
  • Confirm the merge direction and age alignment are intentional.
  • Check units: ppmv, degrees C, and years before present.
  • Verify the forecast horizon and model assumptions locally.
  • Re-run the notebook blocks that use curve fitting or PyMC.

If the explanation diverges from the code, fix the prompt and ask again before you trust the summary.

Workflow

A practical loop: ask, verify, revise

  1. Paste the notebook export.
  2. Ask ChatGPT for a block-by-block summary.
  3. Ask for the file map and the assumptions.
  4. Check the source files locally.
  5. Revise until the explanation matches the code.
  6. Turn the verified steps into speaker notes or slides.

The model is good at explanation and organization. The local files remain the authority.
